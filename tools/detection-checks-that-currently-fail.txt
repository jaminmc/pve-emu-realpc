List of detection checks that currently cannot be bypassed. The source code for this detection software is at: https://github.com/LordNoteworthy/al-khaser - you can compile it yourself using VS2022 (must be this version, older ones won't compile) to test the issues below.
You can also use pafish64.exe for detection testing, source: https://github.com/a0rtega/pafish - requires Mingw to compile; alternatively download a pre-built executable.
Note: pafish and al-khaser are the two gold standards for VM environment detection.

Overall, pafish and al-khaser currently have only 1 check that cannot be bypassed:
1. Checking Local Descriptor Table location - I tested this on several physical machines and they also fail

My personal recommendation is to passthrough a SATA or M.2 drive to the VM, along with a wired physical NIC (USB NIC) for testing.
